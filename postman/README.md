# Todo Application Postman Assets

This directory contains the reusable Postman collection and environment used for manual API testing.

## Files

- `todo-application.postman_collection.json`
- `todo-application.postman_environment.json`

## Usage

1. Import the collection into Postman.
2. Import the environment.
3. Select **Todo Application - Local**.
4. Authenticate using the Login endpoint.
5. Update the environment variables as required.
6. Execute the API requests.

For detailed setup instructions, refer to:

`docs/api/postman-guide.md`
