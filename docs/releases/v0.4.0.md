## Summary

v0.4.0 completes the read-only Task Management Core milestone. It builds on the released v0.3.1 foundation and delivers Task collection and detail retrieval with server-driven discovery, URL-backed state, controlled states, and documented validation.

## Current Architecture

UI pages and components
-> TanStack Query hooks
-> Task services
-> shared Axios apiClient
-> REST API

API failures pass through the service boundary and normalizeApiError into AppError before TanStack Query exposes controlled page state. Unexpected React render failures remain the responsibility of ApplicationErrorBoundary.

Runtime Task values are owned by src/constants/taskValues.ts. Compile-time domain types are owned by src/types/tasks.ts, and user-facing labels are owned by src/constants/taskLabels.ts.
