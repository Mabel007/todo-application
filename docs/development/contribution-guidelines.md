## Contribution Process

1. Select a Jira ticket.
2. Create a feature branch.
3. Implement the ticket.
4. Run:

```bash
npm run lint
npm run format
npm run build
```

5. Perform manual testing.
6. Open a Pull Request.
7. Resolve CodeRabbit comments.
8. Merge into `dev`.
9. Update Jira.
10. Update documentation where applicable.
