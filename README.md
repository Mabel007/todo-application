# Todo Application

A modern task management application built with React, TypeScript, and Vite.

## Tech Stack

- React 19
- TypeScript
- Vite

## Prerequisites

- Node.js 22+
- npm 10+

## Getting Started

### Install dependencies

npm install

### Start development server

npm run dev

### Build for production

npm run build
